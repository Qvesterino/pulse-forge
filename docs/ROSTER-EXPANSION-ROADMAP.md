## WAVE 10 — New grooves + their genres (the last uncovered floors)

1. **`trap.bounce`** (98–104, swing 0.2) — New Orleans Triggerman 3-3-2 key,
   call-and-response. Artists: Big Freedia, DJ Jubilee, Juvenile, bounce generic.
   NOTE: the `bounce` style token already exists (baile) — use name "NOLA Bounce"
   and add a separate style token `nolabounce` to avoid the collision.
2. **`trap.miamibass`** (115–125) — 808-roll Miami bass. Artists: 2 Live Crew,
   Luther generic, miami bass generic.
3. **`trap.snap`** (80–95, minimal) — snap/ringtone era. Artists: Dem Franchize
   Boyz, D4L, Soulja Boy, snap generic.
4. **`house.afroswing`** (~104, swing 0.18) — UK afroswing between afrobeat and
   UKG. Artists: J Hus, MoStack, NSG, afroswing generic.
5. **`trap.countrytune`** (75–90) — country rap tunes: blues guitar + trap drums.
   Artists: Lil Nas X generic, country rap generic, Shaboozey.

## ENGINE IDEA (bigger than data): flow density

Sub-genres today differ by drums only. The mechanical divider between
Detroit/Atlanta/NY rap is the RAP FLOW: 16th-note vs triplet vs offbeat.
Proposal: `flowDensity` in IntentSpec (generation-side — a note-grid knob on
the melodic/vocal-chop roles), letting "detroit flow" vs "atlanta flow"
actually pattern the lead/hook differently. Requires generator + dataset work

## SESSION RULES (learned the hard way — keep applying)

1. **First-match shadowing**: roster entries match in order. Before adding a
   name, `grep -in "<name>" src/intent/artists.ts` — the concurrent session
   adds names in parallel waves (culture wave, Vlna 4/6 reconciliations).
2. **Loudness discipline**: `npm run presets:loudness` after ANY factory
   preset change (artist roster entries do NOT need it — they are not
   factory presets). Update the KNOWN_CLAMPED pin explicitly if the audit
   fails.
3. **Counts**: `docs/CURRENT-STATE.md` rows in the SAME commit
   (Factory presets = FACTORY_PRESETS + 6 drum).
4. **Regexes only via Edit/Write tool** — heredoc/node `\b` becomes backspace
   bytes (bit 3× this campaign). Node heredocs are fine for plain data.
5. **Style token ↔ groove id**: resolveGroove tries `${genre}.${style}` with
   spaces stripped, then name match. New styles need the STYLE_PHRASES entry
   - a groove whose id or name matches, and a `names:` test in the artists
     suite.
6. **Genre table order matters**: specific entries (e.g. "future garage",
   "acid trap") must sit ABOVE generic ones ("garage", "funk") — first match
   wins.
7. Reconciliations go in the concurrent session's favor when their version
   is tested and researched; record the decision in AGENT_WORK_LOG.md.
