All six are loaded lazily in dedicated Web Workers with bounded timeouts + circuit breaker + deterministic heuristic fallback (`src/ai/ranking/ranker-client.ts`, `src/ai/symbolic/prior-client.ts`). Inference never runs on the audio thread. Two further models are lazy-fetched on demand (not in git): multilingual MiniLM q8 ~118 MB (`npm run semantic:fetch` → `public/models/semantic/`) and AST AudioSet q8 ~86.6 MB (`npm run audio:fetch` → `public/models/audio/`); both degrade to keyword/heuristic paths when absent. The retrained `hybrid v3` symbolic prior (label smoothing + variant embeddings, logit saturation fix) is the active generation source behind the candidate bank; see `INTENT_ENGINE.md` for the full conditioning chain (semantic embedding, user style vector, SUNO MODE button).

**Melodic prior audit + fix (2026-09-27)** — `docs/MELODIC-PRIOR-AUDIT-2026-09-27.md`. Read-only analysis (`npm run audit:melodic`, `npm run audit:melodic:weights`) plus a pre-registered retrain gate (`python scripts/gate-melodic-retrain.py`, trains a fresh model per fold). Findings: (1) the v1/v2 comparison was never apples-to-apples — v1 trained on 190 samples, v2 on 239; (2) the shipped 15 % split validates on 29 rows / 4 groups (95 % CI ≈ ±18 pp); (3) **`train-symbolic-melodic.py` multiplied the duration gradient by `(wt / n)` twice**, so the head optimised `wt²` (rare-class pull up to 10.2×) and never descended the loss it printed — finite-difference proof: analytic 0.0224 vs true 0.1463; (4) the first pass of this audit also leaked (it evaluated shipped models on splits they had trained on — `audit-melodic-leakage-check.py` shows v2 degree 0.7952 seen vs 0.4828 unseen), so only gate numbers are quoted here; (5) **the one-hot v1 recipe cannot represent dnb** — `melodicGenreOf()` maps it to house, so all 49 dnb rows carry the house one-hot block (`audit-melodic-dnb-onehot.py`) and the runtime conditions dnb as house on the v1 path; the embedding v2 is the only recipe with a dnb centroid. **Fix applied:** delete the double multiply, `--weight-power 0.5` (sqrt tempering, ratio 10.2× → 3.2×), shared trainer primitives in `train_symbolic_melodic_lib.py`; v2 retrained and validated.

**Melodic depth wave (2026-09-27, ds.v3)** — the audit's remaining data gaps are closed for dnb. `MELODIC_BY_STYLE` dialects (dnb.techstep/ragga/sambass/halftime/crossbreed/minimal + jungle, and the earlier amapiano/metal/dembow/… set) now reach BOTH generators: `generate-symbolic-melodic-dataset.mts` emits `symbolic-melodic-ds.v3` at **861 rows / 119 groups** (was 239/33), and `generate-augmented-data.mts` walks the dialect maps too (**12 672 augmented rows**, of which dnb 3 784 — dialect groups 576; dnb was 0 before). The embedding conditioning is now **style-aware** in one shared `SemanticLookup` (trainer + gate + all audit scripts): a dialect group (`dnb.techstep#…`) resolves to that style's vector, a genre group (`dnb#…`) to the genre centroid; a missing prefix **fails loudly** instead of silently zero-filling (the zero-fill was why the gate died with "genre outside the vocab" the moment dialect rows entered the dataset). Retrained v2 (gate 5-fold PASS): honest degree **0.5354**, duration **0.5621**; shipped-split degree **0.5766**, duration **0.5676** (was 0.5517/0.5517); manifest reports valDegreeAcc 0.5946 / valDurationAcc 0.5766, sha `c00cfb972990b61e`. The augmentation writer is now atomic-with-retry (`write-temp + rename`) so a transient Windows lock on the 260 MB drum dataset can no longer kill a regeneration.

**MIDI corpus W2 (2026-10-04) — pipeline ODHADNUTÝ, `--gate FAIL`** — `docs/W2-MIDI-CORPUS-AUDIT-2026-10-04.md`. Public-domain MIDI corpus added to the melodic prior's _training_ path (train-only, validation stays library-pure). **New:** `scripts/fetch-midi-corpus.mjs` (replayable, only `license === "Public Domain"`, SHA-1 verified per piece), `scripts/ingest-midi-corpus.mts` + pure core `src/ai/midi-corpus-ingest.ts` (Krumhansl key detect from MIDI chroma, conservative 3-role split, 16-step quantize, degree inversion, wrap-around), `scripts/append-classical-embeddings.mts` (adds `classical.{baroque,classical,romantic,impressionist,modern}` to `style-embeddings.json`, 194→199 styles), `--midi-corpus` flag on `train-symbolic-melodic.py` + `gate-melodic-retrain.py` (shared merge code), `tests/midi-corpus-ingest.test.ts` (20). **Corpus: 345 PD pieces → 29 730 next-note rows (338 ingested).** Closes the ds.v3 data gaps: **d1 0→3 491, d5 0→2 935, duration-8 54→736** rows. **Gate verdict: FAIL (degree 0.5447 → 0.4774 pooled, −0.067 on the electronic library val)** — consistent across 2/3-fold, both conditioning regions (`classical.*` and `ambient`) and all role subsets. Classical counterpoint's stepwise/legato distribution over-trains against the electronic syncopated bank. **Decision: NOT shipped in the melodic prior**; the corpus + pipeline are the training base for the planned W1 chord-aware model. Shipped `symbolic-melodic-v2` is unchanged (opt-in flag only).

**DnB retrain (2026-09-26)** — the DnB vocabulary wave extended the drum dataset from `symbolic-prior-ds.v1` (87 552 samples / 33 grooves) to **`symbolic-prior-ds.v2` (95 232 samples / 64 grooves)** by training all seven `dnb.*` grooves through the semantic pack (`style-embeddings.json` gained the dnb centroids + variants; the frozen one-hot `PRIOR_STYLE_VOCAB` is untouched).
