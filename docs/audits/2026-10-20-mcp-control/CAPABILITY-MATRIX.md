# KYX MCP Capability Matrix

**Audited:** 2026-10-20. “Supported” means discoverable, validated, executed against authoritative state, observable, and covered by tests. `PARTIAL` means one or more of those conditions is missing or intentionally limited. `UNSUPPORTED` means the live MCP catalog does not expose the action. See [`ARCHITECTURE-AND-FINDINGS.md`](./ARCHITECTURE-AND-FINDINGS.md) for the transport map and ranked defects.

## Tool families present in the MCP catalog

`kyx_intent`, `kyx_state`, `kyx_undo`, `kyx_transport`, `kyx_export`, `kyx_audio_preview`, `kyx_generate`, `kyx_groove`, `kyx_fx`, `kyx_sections`, `kyx_markers`, `kyx_tracks`, `kyx_pattern`, `kyx_steps`, `kyx_notes`, `kyx_music`, `kyx_catalog`, `kyx_plugin_param`, `kyx_meter`, `kyx_automation`, `kyx_clips`, `kyx_batch`, `kyx_loudness`, `kyx_import_sfz`, `kyx_publish_gallery`, `kyx_render_summary`, `kyx_diagnose_mix`, `kyx_mix_idea`, `kyx_checkpoint`, `kyx_mix`, `kyx_arrange`, `kyx_song`, `kyx_routing`, `kyx_unsuno`, `kyx_master`, `kyx_takes`, `kyx_blind_ab` (`src/mcp/tools.ts:304-1628`).

The catalog is substantially capable for composition and edit operations, but project lifecycle, live recording controls, complete selection context and several mixer/timeline actions remain outside MCP. Schema coverage is broader on inputs than outputs; fourteen of 37 tools publish output schemas after the SFZ import, undo, blind A/B, mix-idea, genre-mix, arrangement and take-management read-back increments below.

Post-audit update: `kyx_import_sfz` returns a bounded structured read-back with imported track/sample IDs and counts; `kyx_undo` returns requested/completed counts and reverted labels; `kyx_blind_ab` returns structured plans, trials and verdicts with idempotent bounded session writes. `kyx_mix_idea` returns a structured plan/apply/rejection result and a compact measured preview without project snapshots or commands. `kyx_mix` returns applied, neutral and already-matched outcomes; mood and overrides are bounded and runtime-validated. `kyx_arrange` returns post-commit scene, clip and cue IDs/counts, plus per-section positions, and rejects invalid energy/length before mutation. `kyx_takes` returns a compact take-group inventory with stable group/take IDs and clip counts; activation and deletion verify the committed state and report undo steps. `kyx_routing createGroup` now creates and names a bus through one canonical command and returns its verified ID/name and undo step. Web and desktop relay tests cover these results. Mix-idea suites passed 166/166; genre-mix suites passed 55/55; arrangement suites passed 58/58; the take-management increment passed 174/174 focused MCP tests; the routing undo-parity increment passed 147/147 command/MCP tests. Strict typecheck, MCP mirror verification and changed-file Prettier pass. The full suite before blind A/B hardening passed 12,672 tests, skipped 129 and had one in-flight plugin-audit measurement failure. The latest `npm run test:expectations` run passed 1,139 files: 12,699 passed, 129 skipped, 1 todo and 0 failed; the suite ledger ratchet holds. Repository-wide `format:check` still reports six unrelated files. The other 23 tools still do not declare output schemas.
