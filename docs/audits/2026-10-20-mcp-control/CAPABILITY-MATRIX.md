## Tool families present in the MCP catalog

`kyx_intent`, `kyx_state`, `kyx_undo`, `kyx_transport`, `kyx_export`, `kyx_audio_preview`, `kyx_generate`, `kyx_groove`, `kyx_fx`, `kyx_sections`, `kyx_markers`, `kyx_tracks`, `kyx_pattern`, `kyx_steps`, `kyx_notes`, `kyx_music`, `kyx_catalog`, `kyx_plugin_param`, `kyx_meter`, `kyx_automation`, `kyx_clips`, `kyx_batch`, `kyx_loudness`, `kyx_import_sfz`, `kyx_publish_gallery`, `kyx_render_summary`, `kyx_diagnose_mix`, `kyx_mix_idea`, `kyx_checkpoint`, `kyx_mix`, `kyx_arrange`, `kyx_song`, `kyx_routing`, `kyx_unsuno`, `kyx_master`, `kyx_takes`, `kyx_blind_ab` (`src/mcp/tools.ts:304-1628`).

The catalog is substantially capable for composition and edit operations, but project lifecycle, live recording controls, complete selection context and several mixer/timeline actions remain outside MCP. Schema coverage is broader on inputs than outputs; twenty-four of 37 tools publish output schemas after the SFZ import, undo, blind A/B, mix-idea, genre-mix, arrangement, take-management, routing, marker, section, musical-state, note, drum-step, transport, groove, catalog and plugin-parameter read-back increments below. Follow-up metrical tests now pin 6/8 bar/beat handling across transport, markers, automation, pattern summaries, generation and generated arrangement placement; generation rejects whole-bar lengths that the canonical 16-step generator cannot represent exactly.

Post-audit update: `kyx_import_sfz` returns a bounded structured read-back with imported track/sample IDs and counts; `kyx_undo` returns requested/completed counts and reverted labels; `kyx_blind_ab` returns structured plans, trials and verdicts with idempotent bounded session writes. `kyx_mix_idea` returns a structured plan/apply/rejection result and a compact measured preview without project snapshots or commands. `kyx_mix` returns applied, neutral and already-matched outcomes; mood and overrides are bounded and runtime-validated. `kyx_arrange` returns post-commit scene, clip and cue IDs/counts, verifies every scene/clip/marker against its planned position, lays sections contiguously, and rejects invalid energy/length before mutation. `kyx_takes` returns a compact take-group inventory with stable group/take IDs and clip counts; activation and deletion verify the committed state and report undo steps. `kyx_routing` publishes route, group and return/send inventories, reports verified post-commit changes and explicit no-op statuses, and resolves ambiguous names as errors. `kyx_markers` lists stable marker IDs and positions, accepts exact IDs for rename/removal, uses meter-aware bar/tick conversion, verifies the post-commit marker state and reports repeated rename as a no-op. `kyx_sections` lists stable section IDs, verifies add/remove/duplicate/reorder/resize/intensity against committed state, resolves exact or unique targets, and makes repeated size/intensity and boundary reorder writes no-ops. `kyx_music` strictly validates integer/range/key inputs, supports absolute 1–128 sixteenth-step pattern lengths, reports committed tempo/key/meter/pattern read-back, and distinguishes complete, no-note and MIDI-boundary partial transpositions. `kyx_notes` lists stable note IDs in bounded pages, accepts noteId targeting, and publishes verified structured read-back for its operations; transpose groups canonical note moves into one undoable snapshot and verifies full or partial committed shifts; track-scoped `kyx_notes quantize` uses a canonical optional target ID to protect unrelated tracks. `kyx_steps` rejects malformed or out-of-range indexes atomically, bounds pad/cell fan-out, skips repeated no-op writes, and returns exact committed cell values, per-pad hit counts and meter-aware fractional pattern lengths. `kyx_groove` rejects invalid directions/percentages, refuses ambiguous section roles in favor of stable `sectionId` targeting, avoids semantic global no-op undo steps, and returns verified global values or scene microtiming cell diffs. Web and desktop relay tests cover structured results. The metrical follow-up passed 156/156 focused MCP and ADR 0057 tests; typecheck and mirror verification pass. `kyx_catalog` now returns structured inventories and full parameter metadata. The other 13 tools still do not declare output schemas.

Plugin parameter update: `kyx_plugin_param` returns schema-backed bounded instance inventories and verified native-value writes, with per-track before/requested/committed values, clamp status, explicit no-op outcomes and partial-target failures. It rejects malformed targets and non-finite values before the canonical `setEffectParam` command and creates no undo step for a repeated value.

Plugin parameter verification: the focused MCP/desktop/mirror set passed 212/212; typecheck and mirror verification passed. The final suite passed all 1,142 files and 12,793 tests (129 skipped, one todo), and the suite-expectations ratchet held.

Transport update: `kyx_transport` now publishes structured results for action and state reads, validates integer 1-based bars and beats against the 8,192-bar project ceiling, resolves one scene by exact ID/name/role/index, and marks a seek partial when an exposed playhead does not land within four ticks. Web and desktop relay tests cover structured position, loop, and transport-state results. The latest step/transport/MCP/mirror/agent-map run passed 242/242; bridge bucket isolation passed 3/3 (245/245 combined).

Groove verification update: `kyx_groove` rejects malformed inputs, targets an exact scene ID when roles repeat, routes edits through the canonical groove intent, and compares committed values/cells before reporting success. The integrated groove/step/transport/MCP/relay/mirror/agent-map/bridge suite passed 249/249; typecheck, mirror verification, changed-file Prettier and `git diff --check` passed.
