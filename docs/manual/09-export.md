# Export

`Alt+5` opens the EXPORT panel. Everything renders through the same engine
that plays the project — what you hear is what you get.

## Audio

- **WAV** — full quality render of the song (or a selected time range) through
  the master chain.
- **MP3** — for sharing; bitrate selectable.
- **Stems** — render selected tracks as separate files (groups/returns
  respected), for mixing elsewhere.

## Video

Render the project against an on-brand canvas visualization — waveform,
playhead, step pulse — as a vertical clip ready for Reels/Shorts/TikTok.
Rendering is real-time (a 15-second export takes 15 seconds) with progress
reporting.

## Score

Export the project's notes as a score document for notation software.

## Share codes

The SHARE option produces a compact text code containing the whole project
(audio references included). Anyone pasting the code into their KYX gets a
working copy — the smallest possible "send you the file".

## Sound design hand-off

Frozen tracks and bounced ranges are ordinary audio clips — select a track,
bounce it (`Ctrl+B` on a selection), and it becomes a normal clip you can
export, group or delete the original of.

## Project files

Projects live in your browser's storage. Use the project browser's export to
save a project file to disk, and import to restore — useful before big
experimental edits, or to move between machines.
