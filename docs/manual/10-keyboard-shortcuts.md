# Keyboard shortcuts

The complete reference. `?` shows the same list inside the studio.
Everything below respects focus: no shortcut fires while you are typing in a
text field.

## Transport

| Key       | Action                             |
| --------- | ---------------------------------- |
| `Space`   | Play / pause                       |
| `Escape`  | Stop (clears help/selection first) |
| `Home`    | Return to start                    |
| `,` / `.` | Playhead −1 bar / +1 bar           |
| `L`       | Toggle loop region                 |
| `S`       | Force save                         |
| `Z` / `Y` | Undo / redo                        |

## Tracks

| Key                 | Action                |
| ------------------- | --------------------- |
| `1`–`9`             | Select track 1–9      |
| `Tab` / `Shift+Tab` | Next / previous track |
| `M`                 | Mute selected track   |
| `S`                 | Solo selected track   |

## Patterns

| Key                   | Action                                      |
| --------------------- | ------------------------------------------- |
| `Ctrl+D`              | Duplicate active pattern                    |
| `PageDown` / `PageUp` | Next / previous pattern                     |
| `Delete`              | Delete selected note / clear selected steps |

## Clips and arrangement

| Key                            | Action                                             |
| ------------------------------ | -------------------------------------------------- |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Copy / cut / paste clips (paste at playhead)       |
| `←` / `→`                      | Nudge selected clips one bar (`Shift` = fine 1/16) |
| `M`                            | Mute / unmute selected audio clips                 |
| `Ctrl+E`                       | Separate the audio clip at the playhead            |
| `X`                            | Crossfade the selected clips                       |
| `Ctrl+B`                       | Bounce the selected range to an audio clip         |
| `P`                            | Locators to selection (loop)                       |
| `J`                            | Toggle the snap grid (restores the last grid)      |
| `Ctrl+G` / `Ctrl+Shift+G`      | Group / ungroup selected clips                     |
| `Shift+L`                      | Lock / unlock selected clips                       |
| `A`                            | Capture the last take (after stop/pause)           |
| `Alt`+drag body / edge         | Slip content / time-stretch                        |

## Piano roll

| Key       | Action                                         |
| --------- | ---------------------------------------------- |
| `← →`     | Nudge notes by one step                        |
| `↑ ↓`     | Nudge notes by one semitone (`Shift` = octave) |
| `S`       | Strum selected notes                           |
| `Alt+S`   | Slide (portamento) toggle                      |
| `L`       | Legato                                         |
| `Ctrl+B`  | Duplicate selected notes                       |
| `Alt+Q`   | Quantize 50 %                                  |
| `Shift+C` | Chord stamp menu                               |

## Dice tray (when open)

| Key             | Action                |
| --------------- | --------------------- |
| `D` / `Shift+D` | Roll full / vary      |
| `←` / `→`       | Walk the roll history |

## Assist

| Key            | Action                            |
| -------------- | --------------------------------- |
| `Ctrl+Shift+V` | One-click vary (seeded variation) |
| `Ctrl+Shift+F` | One-click fill                    |

## Panels

| Key               | Panel                                                                                      |
| ----------------- | ------------------------------------------------------------------------------------------ |
| `Alt+1` … `Alt+9` | Mixer, track devices, arrangement, modulation, export, dice, intent, MIDI input, mastering |
| `Alt+0`           | TSAR engine panel                                                                          |
| `?`               | This help                                                                                  |

## Mouse conventions

- `Ctrl`+click toggles a clip in the selection; `Shift`+click range-selects.
- `Ctrl`+wheel zooms the timeline around the cursor.
- `Alt`+drag an audio clip's body slips its content; `Alt`+drag an edge
  time-stretches.
- Right-click opens context menus; on touch devices a long press does the same.
