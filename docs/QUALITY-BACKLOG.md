## D. Inconsistencies (document or unify — decide, then act)

- dB output ranges: ±12 / ±18 / ±24 / −24..+12 families across effects.
- Threshold ranges: −60 (compressor/sidechain) vs −80 (gate) vs −24 (limiter).
- Instrument level semantics: dB `LEVEL` (analog/bass/fm/keys…) vs linear `GAIN` (808/sampler/granular/vocalchop).
- RESO max: worklet path normalizes to self-osc ceiling, biquad fallback writes Q=12 raw (~+22 dB peak) — same knob, different max per voice path.
- `process.env.NODE_ENV`-style note: attack/release stored in SECONDS across the dynamics family (consistent internally; only the DISPLAY was broken — A2).
