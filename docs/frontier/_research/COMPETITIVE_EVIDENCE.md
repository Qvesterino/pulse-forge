# Competitive Evidence — AI-Assisted Audio Workstations (AAW)

**Purpose:** source-backed competitive landscape for the KYX frontier report on AI-Assisted Audio Workstations.
**Research cutoff:** 2026-10-25 (all "as of" statements mean this date).
**Compiled:** 2026-10-25.
**Method:** official vendor documentation and release notes first (grade **A**), then reputable independent reporting (**B**), then secondary/aggregator reporting (**C**). Anything that could not be confirmed on a first-party page is written **NOT VERIFIED** — it is never upgraded from marketing copy.

**Fairness rules applied**

- A row only claims a capability that a cited page states. Absence of a feature is written as "no such feature found in the pages reviewed", not as "does not exist".
- Every row carries a **Runs** column (local / cloud / hybrid / n-a) and a **Type** column.
- Version and date claims name the release they belong to.
