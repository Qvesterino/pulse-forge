# Instrument Parameter Verdicts — Phase 3b classification

Companion to `docs/PLUGIN-AUDIT-2026-09-27.md`. Classifies every parameter the
sweep measured "below 2 % delta at extremes" (146 across 22 instruments), so
"below-metric" never gets mistaken for "dead".

**Method.** The sweep now renders each instrument with a note ON at 0.05 s
(0.35 s hold) + explicit note OFF at 0.40 s and measures three windows:
attack 0.05–0.15 s, sustain 0.20–0.35 s, release 0.42–0.70 s, plus the
full-buffer RMS / side energy / spectral centroid / block-dynamics set. A
parameter is _wired_ if any window or full-buffer metric moves > 2 % at an
extreme. Percussive one-shots (808, logdrum, drumsynth) are swept WITHOUT an
explicit noteOff — their decay tails are the instrument's voice.

**Verdict classes.**

- **WIRED** — responds in the sweep (not listed below).
- **TRANSIENT-WIRED** — steady-state metrics miss it, attack/release windows
  respond (listed as `transientWired` in the report JSON).
- **ROUTING-ONLY (mod-matrix slots)** — `modASrc/modADst/modAAmt/modBSrc/
modBDst/modBAmt/modLfoRate`. Inert at the default amount of 0 by design;
  the routing itself is verified (probe: analog LFO→cutoff route at full
  amount moves attack +3.6 %, tail +6.5 %).
- **CONDITIONAL-BY-DESIGN** — wired, but gated by another param's default:
  sampler `decay` (skipped at SUSTAIN 1 — the ADSR contract), sampler
  `loop/loopStart/loopEnd/loopXfade` (gated by LOOP), `velFlt` (expresses at
  velocity ≤ 0.9), `pitchDecayT`/808 `pitchDrop` (pitch-drop pairs with
  P-DROP depth), analog `spread` (audible from UNISON ≥ 2),
  wavetable `table`-family with a track sample attached (the table is then
  extracted from the sample — the factory-table mode responds, verified),
  texture `hold/gate` (granular freeze states).
- **SUB-THRESHOLD BY DESIGN** — intentionally subtle layers under the 2 %
  bar on this signal: 808 `click`, drumsynth `snap`, bell `shimmer`/`strike`,
  organ `click`, clav `pick`/`growl`, 808 `mono` (legato semantics).
- **PROBE-LIMITED** — wired in real use, not expressible by this probe:
  every `glide` (needs slideFrom legato, not single isolated notes),
  vocalchop `shift/vowel/morph/sharp` (the chop content at pitch 45 with a
  pluck sample renders near-silent — needs vocal-register material),
  sampler `release` on one-shot samples shorter than the hold (audible for
  samples/loops longer than the note).
- **FIXED during this audit** — params that were genuinely dead and now pass:
  - `release` on **analog, bass, sampler, wavetable, fm, keys, pluck, flute,
    organ, acid, vocalchop**: the voice-manager stop callback cancelled the
    scheduled release envelope and hard-gated at 10 ms, so the RELEASE knob
    was dead whenever a note ended via noteOff (every MIDI note-off). All 11
    stop callbacks are release-aware now (tau = release/4, node stops at
    release·3 + 0.1 s); regression: browser-check "analog RELEASE knob
    shapes the post-noteOff tail".
  - 808 `decay`: visible again — the percussive sweep no longer chokes the
    tail with an explicit noteOff (probe: decay 0.05 s → tail 0.236 RMS,
    decay 4 s → 0.698).
  - wavetable `table`: visible again — synth instruments audition without a
    track sample so the factory-table mode responds (probe: table 3 moves
    RMS −26 %).
