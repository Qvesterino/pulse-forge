chore: remove the temporary new-metric probe

scripts/_probe-newmetric.mjs was a throwaway diagnostic that compared four
candidate metrics (postAmp, fullAmp, fullCorr, fullEnv) for signal-to-noise
against a genuine noise control. Its findings are now recorded in the code
comments of src/plugin-audit-checks.ts and in the commit message for the
envelope metric, so the script itself has no reason to stay in the tree.

It ended up tracked because a parallel session committed the working tree
while it was still on disk.
